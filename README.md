# Auto Logo Challenge

Joc educativ pentru copii cu 120 de sigle, 6 niveluri și pronunțarea automată a fiecărei mărci.

## Pornire

Deschide `index.html` sau încarcă toate fișierele în rădăcina repository-ului GitHub Pages.

- Parola: `Mark2020.`
- Siglele: `assets/logos/`
- Sunetele jocului: `assets/sounds/`
- Lista mărcilor: `data.js`
- Logica jocului: `game.js`

Pronunțarea pornește după răspunsul corect și poate fi repetată cu butonul difuzor. Este realizată local de vocea disponibilă în browserul telefonului.

Jocul nu folosește fotografii cu mașini și nu încarcă imagini externe în timpul jocului.
